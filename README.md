# КиноВектор

**Дисциплина:** Жизненный цикл разработки программного обеспечения  
**Выполнил:** студент группы 450503 Красько А.П.  
**Лабораторная работа:** № 4 «Разработка и документирование системных требований» (продолжение № 3)

## Описание проекта

«КиноВектор» (KinoVector) – учебный web-сервис рекомендаций фильмов. Сервис помогает зрителю быстрее выбрать фильм, ведёт каталог, собирает пользовательские оценки и текстовые рецензии, хранит историю просмотров и формирует персональную ленту рекомендаций на основе предпочтений пользователя.

Проект создаётся как B2C-сервис для условного заказчика «СинемаЛайн». В MVP входят каталог, поиск, фильтры, карточка фильма, оценки, рецензии, история просмотров, персональные рекомендации с объяснениями, подборки, дайджест, модерация и администрирование каталога. Онлайн-просмотр фильмов, платежи и нативные мобильные приложения в границы MVP не входят.

## Бизнес-цели

- сократить время выбора фильма до 2 минут;
- повысить удержание и месячную аудиторию сервиса;
- увеличить долю пользователей, оставляющих оценки и рецензии;
- собрать данные о предпочтениях аудитории для контент-команды;
- обеспечить соответствие требованиям законодательства о персональных данных.

## Технологии

- язык backend: C++20;
- web-фреймворк: Drogon;
- база данных: PostgreSQL 16;
- кэш и сессии: Redis 7;
- frontend: Vue.js 3, Bootstrap 5;
- сборка: CMake;
- контейнеризация: Docker Compose;
- внешние данные: TMDB API с кэшированием и fallback;
- документация: Markdown, SysML v2, Graphviz, Typst;
- система контроля версий: Git.

│   ├── kinovector.sysml      # SysML v2-модель
