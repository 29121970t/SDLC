# КиноВектор

**Дисциплина:** Жизненный цикл разработки программного обеспечения  
**Выполнил:** студент группы 450503 Красько А.П.  
**Лабораторная работа:** № 3 «Разработка и документирование бизнес-требований»

## Описание проекта

«КиноВектор» (KinoVector) — учебный web-сервис рекомендаций фильмов. Сервис помогает зрителю быстрее выбрать фильм, ведёт каталог, собирает пользовательские оценки и текстовые рецензии, хранит историю просмотров и формирует персональную ленту рекомендаций на основе собственных предпочтений и поведения других пользователей.

Проект создаётся как B2C-сервис для условного заказчика «СинемаЛайн». В MVP входят каталог, поиск, карточка фильма, оценки, рецензии, история просмотров, рекомендации, модерация и администрирование каталога. Онлайн-просмотр фильмов, платежи и нативные мобильные приложения в границы MVP не входят.

## Бизнес-цели

- сократить время выбора фильма до 2 минут;
- повысить удержание и месячную аудиторию сервиса;
- увеличить долю пользователей, оставляющих оценки и рецензии;
- собрать данные о предпочтениях аудитории для контент-команды;
- обеспечить соответствие требованиям законодательства о персональных данных.

## Технологии

- язык backend: C++20;
- web-фреймворк: Drogon;
- база данных: PostgreSQL 16;
- кэш и очереди: Redis 7;
- frontend: серверный HTML, HTMX, Bootstrap 5;
- сборка: CMake;
- контейнеризация: Docker Compose;
- внешние данные: TMDB API с кэшированием и fallback;
- документация: Markdown, SysML v2, PlantUML;
- система контроля версий: Git.
